# Платформа PWA + CRM для автосервисов г. Актау (`car-pwa`)

Мобильное PWA-приложение онлайн-записи и облачная CRM-панель приёмщика (Order Workflow Manager) для 25 реальных автосервисов Актау, собранных из 2ГИС (у которых нет собственного сайта).

## Возможности
- **25 готовых сайтов-приложений (PWA) под СТО Актау:** каждый по адресу `/<slug>` (например, `/my-service`, `/amir-performance`, `/vest-avto`, `/veraton-auto`, `/arlan`, `/turbo-motors`, `/yasira-motors`).
- **Реальные данные из 2ГИС:** название, адрес в микрорайонах Актау, телефоны, ссылки на WhatsApp, график работы, рубрики услуг, главное фото и последние 5-звёздочные отзывы клиентов.
- **Дефолтный мастер-шаблон:** `/default-sto` (и CRM `/default-sto/admin`).
- **Установка как нативное приложение (PWA):** работает с телефона через «Добавить на главный экран» (`manifest.json` + `sw.js`).
- **CRM-кабинет владельца (`/<slug>/admin`):**
  - Вход по паролю (`1234` или `pGE-HsT-Fc8-rdA`) либо быстрый демо-вход в 1 клик для презентации владельцу СТО.
  - Фильтрация по статусам (`Новая заявка`, `Подтверждена`, `В боксе (Ремонт)`, `Готово к выдаче`, `Выдано клиенту`), поиск по авто/номеру, подсчёт выручки в тенге (`₸`) и отправка уведомления клиенту в WhatsApp в 1 клик.
- **Каталог для продаж (`/`):** на главной странице — список всех 25 СТО Актау с кнопкой быстрой отправки готового коммерческого предложения прямо в WhatsApp владельцу.

## Масштабирование на новые города или ниши
1. В папке `2gis-parser` лежит готовый парсер `VllSunday/2gis-parser`.
2. Скрипт `scraper/fetch_aktau_2gis.py` автоматически отбирает компании без сайта с высоким рейтингом и отзывами.
3. Скрипт `scraper/build_configs.py` генерирует конфиги в `src/data/stores.json` и `src/services/<slug>/config.json`.
