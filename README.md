# saas-buisnes
Создай готовое веб-приложение (PWA) для онлайн-записи в автосервис или детейлинг-студию. Интерфейс должен выглядеть ультрасовременно, дорого и технологично — в стиле продуктов Apple или Tesla: глубокий черный фон (#0A0A0C), чистый белый текст и настраиваемый акцентный цвет (по умолчанию глубокий синий #4690FF, но с возможностью легкой смены на красный или другой оттенок через конфигурацию) с эффектами полупрозрачного стекла (Glassmorphism).

Приложение должно работать по прямой ссылке как на компьютере, так и на телефоне (без обязательной регистрации для клиентов, с возможностью установки на главный экран телефона как PWA).

АРХИТЕКТУРА, СКОРОСТЬ И МАСШТАБИРОВАНИЕ:
- Система должна поддерживать неограниченное масштабирование через общую папку `services` в репозитории. Внутри папки `services` находится базовый шаблонный файл `index.html` (со всем необходимым CSS и JS внутри или рядом), а также отдельные папки для каждого автосервиса (например, service-1, service-2, ..., service-20), куда при необходимости можно легко добавлять новые.
- В папке каждого конкретного сервиса лежит свой файл `index.html`, который ссылается на общий шаблон, а также локальный конфигурационный файл (например, `config.js` или `config.json`), содержащий все уникальные данные этого сервиса. Это позволяет каждому автосервису хранить свои данные локально для максимальной производительности, не нагружая базу лишними запросами.
- Перечень данных, которые собираются и прописываются в локальный конфиг каждого сервиса:
  1. Название автосервиса / детейлинг-центра.
  2. Логотип студии.
  3. Главное изображение (баннер / карточка, где изображена машина или бокс именно этого детейлинг-центра).
  4. Контакты (адрес в городе, телефон, мессенджеры).
  5. График работы и выходные дни.
  6. Прайс-лист услуг (названия, цены, длительность).
  7. Фотографии выполненных работ (галерея).
  8. Кастомный акцентный цвет (например, синий, красный или другой на выбор).
  *Примечание:* Если у какого-то сервиса отсутствуют фотографии, логотип или отзывы, система должна автоматически подставлять красивые шаблонные заглушки-фоллбэки, не ломая интерфейс лендинга.
- Используй React, Vite, TypeScript и Tailwind CSS.

БАЗА ДАННЫХ SUPABASE (Две раздельные таблицы для неограниченного роста):
1. Таблица `stores`: Хранит идентификатор студии (slug), название, контактные данные, настройки и хеш/пароль администратора для входа в защищенную панель.
2. Таблица `bookings`: Универсальная таблица для накопления записей клиентов всех студий без ограничений по количеству (поля: ID, store_slug, имя, телефон, машина, дата/время, статус). Записи каждого отдельного сервиса изолированы по его `store_slug`, что позволяет каждому автосервису независимо принимать десятки и сотни клиентов.

СТРУКТУРА ПРИЛОЖЕНИЯ И ЭКРАНЫ:
1. Клиентская часть (Главная страница):
   - Шапка с логотипом студии, индикатором статуса (например, «Демо-версия системы») и кнопкой быстрого вызова.
   - Главный экран (Hero): Большое качественное фото автомобиля/студии, название, краткое описание и заметная кнопка с эффектом стекла «Записаться в студию».
   - Блок услуг и цен: Список услуг с ценами и длительностью.
   - Галерея работ: Карточки с фотографиями и описанием выполненных работ (с учётом фоллбэков при отсутствии фото).
   - Интерактивная форма записи: Клиент выбирает услугу, свободную дату и время (с учетом занятости боксов и графиков работы), вводит имя, телефон и марку машины, после чего подтверждает запись. Занятое время должно быть заблокировано. Записи напрямую улетают в таблицу `bookings` в Supabase.
   - Нижняя навигационная панель (для мобильных): «Главная», «Услуги», «Моя запись» со стильным стеклянным эффектом (backdrop-filter: blur), которая не перекрывает контент.

2. ИИ-Ассистент (AI виджет):
   - Добавь плавающий чат-ассистент с готовыми кнопками-подсказками («Когда ближайшее окно?», «Сколько стоит полировка?», «Как найти студию?»). 
   - Ассистент должен отвечать клиенту в рамках расписания и услуг именно этой студии, помогая подобрать свободное время.

3. Кабинет владельца (Admin Panel):
   - Отдельная защищенная страница входа по паролю, сверяемая с таблицей `stores` в Supabase.
   - Дашборд владельца: просмотр записей из таблицы `bookings` на день/неделю, количество заездов, выполненных работ и выручки.
   - Возможность вручную добавлять, переносить или отменять записи, блокировать боксы, менять цены, услуги, часы работы, адрес, телефон и фотографии.
   - Возможность для владельца через чат-помощника в кабинете узнавать базовую аналитику («Что у меня завтра?», «Сколько машин было на неделе?», «Сколько денег получено?»).

Напиши качественный, модульный и чистый код проекта, разделив его на логические компоненты (Клиентская часть, Кабинет владельца, База данных/Конфиг), готовый к деплою на Vercel.
