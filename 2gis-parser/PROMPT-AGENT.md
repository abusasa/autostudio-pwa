# Промпт для запуска сбора через ИИ-агента

Этот файл — для человека, которому поручили собрать один или несколько регионов
Казахстана. Ничего программировать не нужно: всю работу делает ИИ-агент
(Claude Code, Cursor, Codex — любой, у которого есть доступ к терминалу).

---

## Что нужно один раз поставить

| Что | Где взять | Как проверить |
|---|---|---|
| **Google Chrome** | https://www.google.com/chrome/ | Просто откройте браузер |
| **Python 3.10 или новее** | https://www.python.org/downloads/ — при установке на Windows поставьте галочку **«Add Python to PATH»** | `python --version` |
| **Git** | https://git-scm.com/downloads | `git --version` |
| **Агент с доступом к терминалу** | Claude Code: `npm install -g @anthropic-ai/claude-code` | `claude` |

На macOS всё то же самое; Python обычно уже стоит, Chrome ставится перетаскиванием
в «Программы».

## Что делать

1. Откройте терминал (Windows: PowerShell, macOS: Terminal) в любой удобной папке.
2. Запустите агента (`claude`).
3. Скопируйте промпт ниже целиком, впишите свой регион вместо `<РЕГИОН>` и отправьте.
4. Дальше агент всё сделает сам и будет задавать вопросы, если что-то пойдёт не так.

## ПРОМПТ — копировать отсюда

```text
Задача: собрать базу заведений одного региона Казахстана из 2GIS с помощью готового
проекта 2gis-parser. Ты работаешь в терминале, весь проект уже написан — ничего
разрабатывать не нужно, нужно развернуть, проверить машину, запустить сбор
и упаковать результат.

Мой регион: <РЕГИОН>
Адрес репозитория: <ССЫЛКА НА РЕПОЗИТОРИЙ>

Выполни по шагам, не пропуская проверок.

ШАГ 1. Развернуть проект.
- Склонируй репозиторий и перейди в его папку.
- Определи, какой командой запускается Python на этой машине (python, python3 или py),
  и дальше используй именно её.
- Установи зависимости: pip install -r requirements.txt
- Playwright-браузеры ставить НЕ нужно: проект подключается к системному Chrome.
  Команду `playwright install` не запускай.

ШАГ 2. Проверить машину.
- Запусти: python run.py doctor
- Эта команда сама проверит версию Python, зависимости, наличие Chrome, свободное
  место, доступ к 2gis.kz и посчитает рекомендуемое число окон браузера исходя
  из числа физических ядер и объёма оперативной памяти.
- Если какой-то пункт помечен ХХХХ — почини его и повтори проверку.
  Чаще всего это отсутствующий Chrome (нужно скачать с google.com/chrome)
  или неустановленные зависимости.
- Запомни рекомендованное число окон. Не увеличивай его: замеры показывают,
  что выше числа физических ядер скорость не растёт, а доля сбоев растёт втрое.
  Если во время сбора я буду работать за этим компьютером — возьми на 2 меньше.

ШАГ 3. Показать мне план.
- Запусти: python run.py regions
  Покажи мне строку моего региона: сколько там организаций и сколько примерно
  займёт прогон.
- Скажи, сколько окон ты собираешься открыть и почему именно столько.
- Дождись моего подтверждения, прежде чем запускать сбор.

ШАГ 4. Запустить сбор.
- Команда: python run.py collect --region <РЕГИОН> --workers <ЧИСЛО ИЗ ШАГА 2>
- Запусти её в фоне и следи за логами (папка logs/, отдельный файл на каждого воркера).
- Во время прогона откроется несколько окон Chrome — это нормально, закрывать
  и трогать их не нужно, они работают сами.
- Прогон длинный: от получаса до трёх часов в зависимости от региона.
  Периодически показывай мне прогресс командой: python run.py status
- Если я скажу «останови» — нажми Ctrl+C один раз. Прогресс сохранится,
  и продолжить можно будет той же командой.

ШАГ 5. Если что-то сломалось.
- Прогон прервался или упал: просто запусти ту же команду снова — она продолжит
  с того места, где остановилась, уже собранное не потеряется и не соберётся дважды.
- В логах "Антибот-страница" много раз подряд: перезапусти с меньшим числом окон
  (--workers на 2-3 меньше). Это редкость, за все прогоны такого не случалось.
- Не найден браузер: установи Google Chrome либо пропиши путь к нему
  в config.yaml, поле browser.binary_path.
- Кончается место на диске: сырые данные крупного региона занимают до 300 МБ,
  плюс профили браузера. Освободи место и продолжи.
- Всё остальное: покажи мне последние 50 строк из logs/ и своё объяснение,
  ничего не переписывая в коде без моего разрешения.

ШАГ 6. Завершение.
- Когда очереди опустеют (в логе появится "очереди пусты - работа закончена"
  у всех воркеров), собери выгрузку: python run.py export
- Покажи мне итог из out/report.md: сколько всего заведений, сколько из них
  площадок, какая заполненность телефонов и вместимости.
- Упакуй результат: python run.py pack --author "МОЁ ИМЯ"
  Получится файл 2gis-<регион>-<дата>.zip в текущей папке.
- Скажи мне полный путь к этому архиву — я отправлю его координатору.

Важные правила:
- Не меняй код проекта. Твоя задача — запустить его и довести прогон до конца.
- Не выдумывай данные. Если чего-то нет в 2GIS, поле остаётся пустым — так задумано.
- Не запускай сбор в режиме --headless: это повышает риск блокировки.
- Не запускай несколько прогонов одновременно в одной папке.
- Все длинные команды запускай в фоне, чтобы не блокировать сессию.
```

## Если агента нет — то же самое руками

```bash
git clone <ссылка на репозиторий>
cd 2gis-parser
pip install -r requirements.txt

python run.py doctor     # проверит машину и скажет, сколько окон открывать
python start.py          # мастер: выберите регион и число окон, дальше он всё сделает сам
```

`start.py` проведёт по четырём шагам, запустит сбор, а по окончании сам соберёт
выгрузку и предложит упаковать архив для отправки.

## Что происходит во время прогона

Откроется несколько окон Chrome — по одному на «воркера». Они листают выдачу 2GIS
и открывают карточки заведений. Трогать их не нужно, работают сами.

Компьютер будет заметно загружен: браузеры съедят почти все ядра. За машиной можно
работать, но лучше запускать на ночь.

**Ctrl+C в терминале — безопасная остановка.** Текущая карточка дописывается, прогресс
сохраняется в `data/state.sqlite`. Повторный запуск той же команды продолжит с того же
места: уже собранные заведения повторно не открываются.

## Что отправить обратно

Один файл — `2gis-<регион>-<дата>.zip`, который создаёт `python run.py pack`.
Внутри лежат сырые ответы 2GIS и состояние очереди: этого достаточно, чтобы
координатор собрал общую базу командой `python run.py merge <ваш архив>`.
