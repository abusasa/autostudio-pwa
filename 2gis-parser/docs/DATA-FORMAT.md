# Формат выгрузки

`out/venues.csv`, `out/venues.jsonl` и `out/venues.xlsx` — одни и те же записи в одном
наборе колонок. CSV пишется в UTF-8 с BOM, чтобы Excel открывал его без плясок
с кодировкой.

Одна строка — один филиал заведения (`branch_id`). У сети из пяти кафе будет пять строк
с общим `firm_id` и разными `branch_id`.

## Колонки

| Колонка | Что в ней | Заполненность по Алматы |
|---|---|---:|
| `id`, `branch_id` | Идентификатор филиала в 2GIS | 100% |
| `firm_id` | Идентификатор организации: общий у всех филиалов сети | 100% |
| `name` | Короткое название («Асем») | 100% |
| `name_full` | Полное название с уточнением («Асем, банкетный зал») | 100% |
| `category` | Рубрики 2GIS через `;` («Банкетные залы; Кафе») | ~99% |
| `rubric_ids` | Их числовые идентификаторы — по ним удобно фильтровать | ~99% |
| `city` | Населённый пункт: город, а для пригородов — село или посёлок | 99% |
| `district` | Район города | ~75% |
| `region` | Область | — |
| `address` | Адрес и уточнение к нему одной строкой | ~97% |
| `address_comment` | Уточнение отдельно («2 этаж», «вход со двора») | — |
| `postcode` | Почтовый индекс | — |
| `phone` | Все телефоны через `; ` | 86% (89% у площадок) |
| `email` | Почта через `; ` | — |
| `website` | Сайты через `; ` | 19% |
| `social_links` | JSON вида `{"instagram": [...], "whatsapp": [...]}` | 89% |
| `capacity` | **Вместимость числом.** Из диапазона берётся верхняя граница | 40% (86% у площадок) |
| `capacity_raw` | Исходная формулировка («До 350 человек») | — |
| `capacity_source` | `attributes` — структурированное поле 2GIS, `text` — вытащено из описания, пусто — данных нет | — |
| `working_hours` | Часы работы человекочитаемо: `Пн-Пт 09:00-18:00; Сб 10:00-16:00` или `круглосуточно` | 99% |
| `working_hours_json` | Исходное расписание 2GIS как есть | 99% |
| `latitude`, `longitude` | Координаты | 96% |
| `rating`, `reviews_count` | Оценка и число отзывов | — |
| `2gis_url` | Прямая ссылка на карточку | 100% |
| `is_event_venue` | Признак «подходит под мероприятия»: `event_score >= 3` | — |
| `event_score` | Балл пригодности, 0–17 | — |
| `event_reasons` | Из чего сложился балл — расшифровка в открытую | — |
| `source_city` | Код региона, в котором нашли | 100% |
| `source_query` | Первый источник: `rubric:10803` или поисковое слово | 100% |
| `source_queries_all` | **Все** источники, которые нашли это заведение | 100% |
| `collected_at` | Момент сбора, UTC | 100% |

## Вместимость: откуда берётся

Порядок строгий, вниз спускаемся только если выше пусто:

1. `attributes` — структурированный атрибут карточки с тегом, оканчивающимся на
   `_capacity`, например `banquet_rooms_banquetroom_capacity` → «До 350 человек».
   На нём держатся 86% заполненных значений.
2. `text` — число вытащено из описания или названия («вмещает 120 гостей»).
   Такие значения лучше проверять глазами.
3. Пусто — данных нет.

Из формулировки «от 50 до 200 человек» берётся 200: это ёмкость зала, а не минимальный
заказ. Числа вне диапазона 1–20 000 отбрасываются как явный мусор (год, номер дома).

Вместимость не оценивается и не додумывается. Нет её — поле пустое.

## Балл пригодности (`event_score`)

Отдельного флага «площадка для мероприятий» у 2GIS нет, поэтому балл считается сам
и складывается из:

- рубрики: «Банкетные залы», «Аренда лофтов» и подобные дают 4 балла, «Рестораны»,
  «Гостиницы», «Базы отдыха» — 2, «Кафе», «Столовые» — 1 (полные списки в
  `src/venues2gis/classify.py`);
- наличия структурированной вместимости;
- маркеров в названии: «тойхана», «банкет», «зал торжеств», «loft», «event» и т. п.

Порог `is_event_venue` — 3 балла: одной слабой рубрики мало, нужен ещё признак.
Из выгрузки ничего не выбрасывается, `venues_all.csv` содержит все собранные
организации, а порог пересчитывается под свою задачу: `run.py export --min-score 5`.

## Дедупликация

Дубли снимаются на трёх уровнях: `branch_id`, `firm_id` и вторичный ключ
(нормализованное название плюс последние 10 цифр телефона или координаты). Пары, похожие
на дубли, но не совпавшие уверенно, автоматически не склеиваются: они выписываются
в `out/possible_duplicates.csv`, дальше глазами.
